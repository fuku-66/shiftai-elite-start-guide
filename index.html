使い分けフィードバック会とフォローアップサポート会は、どう使い分けますか？⌄

回答実践会で作ったものやその日の疑問はフィードバック会へ。セットアップや操作で止まったときは、フォローアップサポート会を利用します。

  • フィードバック会：原則、実践会の直後に開催。作ったものやつまずきを相談し、次の改善点を確認します。
  • フォローアップサポート会：Skills・Agentsの配置、操作、用語などを少人数で確認します。初心者から利用でき、事前学習の完了前でも相談できます。
  • フォローアップ会は事前質問フォームに困りごとを記入し、最新の開催案内から参加してください。

追加費用ELITEの料金に含まれるものと、別途費用がかかるものは？⌄

回答受講期間中の実践会・フィードバック会・フォローアップサポート会などは契約サービスに含まれます。外部AIツールの有償プランや、一部のイベント費用は別途負担です。

契約の相談期間延長・返金・解約は、どこへ相談しますか？⌄

回答ご自身の契約書を確認し、会員サイトや入会時の案内にある運営窓口へ個別に相談してください。条件・期限は契約内容によって判断されます。

  • 体調などの事情による延長と、エージェントを作成できなかった場合の保証制度は、条件が異なります。
  • 保証は収益や案件獲得を保証するものではありません。申告・チェックイン・特例対応・提出等の条件を運営へ確認してください。
  • 解約を希望する場合は「ELITEのみ」か「SHIFT AI全体」かを明確にし、期限があるため早めに窓口へ連絡してください。

卒業後90日間が終わった後も、利用できるものはありますか？⌄

回答配布されたSkills・サブエージェントは手元に残ります。ライブ参加、質問、アーカイブ、図鑑などは、それぞれ利用期間が異なります。

  • 実践会・FB会・フォローアップサポート会への参加は、原則として受講期間の満了で終了します。
  • 「ELITE限定質問」は、ELITE入会日から1年間が利用期間です。
  • 一部のコミュニティやニュースは、通常会員・生涯プランの会員資格がある間は継続利用できます。案件獲得セミナーも卒業後の参加が案内されています。
  • アーカイブ・図鑑の閲覧や図鑑への提出には個別の期限があります。ご自身の会員資格と卒業・退会時の案内を確認してください。

操作トラブル7件

Claude Code CLIClaude Code CLIが起動しない、またはコマンドが見つかりません。⌄

回答OS、導入方法、バージョンによって手順が変わるため、古い固定コマンドだけで判断しません。現在の環境情報とエラー全文をそろえて切り分けます。

  • OSとバージョン、使っているターミナルを確認する
  • どの案内から導入したかを確認する
  • 実行した操作とエラー全文をそのまま控える
  • 最新の技術案内と照合し、解決しなければ質問する
参考教材：Claude Code CLIセットアップ →
Skills・AgentsSkillsやAgentsが認識されない、配置先が分かりません。⌄

回答配置や読み込み方法は、デスクトップアプリかCLIかで異なります。別環境の手順を混ぜず、使っている環境と導入経路を先に特定します。

  • 利用環境と、ダウンロードした配布物を確認する
  • 参照した案内ページと、実際に行った配置を照合する
  • 現在のセットアップ案内に沿って動作を確認する（教材の最初の4択画面など）
  • 出ない場合は配置先とエラーを添えて質問する
参考教材：事前学習・参加特典を確認する →
Antigravity IDEAntigravity IDEの画面が、教材と違って見えます。⌄

回答アプリ更新やOS差で、ボタン名や配置が変わる場合があります。見た目だけで失敗と判断せず、目的の操作と現在の画面を照合します。

  • アプリとOSのバージョンを確認する
  • 教材で行いたい操作を一文で整理する
  • 現在の画面を、個人情報を隠して添付する
  • 同じ機能が別メニューにないか確認する

設定ファイル設定ファイルやMarkdownファイルが見つからない・編集できません。⌄

回答対象ファイルは利用環境やプロジェクトごとに異なります。推測で新規作成・上書きせず、教材名、ファイル名、開いているフォルダを確認します。

  • どの教材の、何を設定しようとしているかを確認する
  • 開いているプロジェクトと対象ファイル名を確認する
  • 編集前に元ファイルを残す
  • 場所が確定できない場合は画面と状況を添えて質問する

MCP・API・認証MCP、API、OAuthの接続や認証で止まりました。⌄

回答外部サービスごとに権限、料金、設定画面が変わる専門項目です。教材の想定サービスと現在の公式仕様を確認し、認証情報を隠して個別に切り分けます。

  • 接続したいサービス名と目的を明確にする
  • 利用中のプラン、アプリ、バージョンを確認する
  • エラー全文を残す
  • APIキー、トークン、パスワードは画面や質問文へ載せない

安全・権限権限や警告が表示されたとき、許可してよいですか？⌄

回答意味が分からない権限は、すぐ許可しません。何を読み、書き、外部送信する権限かを1つずつ確認します。

  • 読み取り・書き込み・外部通信のどれかを確認する
  • 対象のフォルダやサービスが必要最小限か確認する
  • 秘密情報や顧客データを対象にしない
  • 判断できない場合は警告画面を添えて確認する
参考教材：事前学習・参加特典を確認する →
実装・デバッグ作成中のアプリやエージェントが、期待どおりに動きません。⌄

回答個別実装は、目的・再現手順・期待結果・実際の結果を分けると解決しやすくなります。まず最小の状態で同じ問題が起きるか確認します。

  • 実現したいことを一文で書く
  • 再現手順と、期待した結果を書く
  • 実際の結果とエラー全文を書く
  • 関連する最小限の設定やコードだけを共有する
